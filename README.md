# Foto ke Elemen

Masukkan satu foto, hasilnya elemen-elemen vektor terpisah (XML/SVG) untuk Alight Motion. Semua proses di browser, tanpa build.

Isi: `index.html`, `style.css`, `script.js`

Jalankan: buka `index.html` di browser.

Push ke GitHub:
```bash
git init
git add .
git commit -m "Foto ke Elemen"
git branch -M main
git remote add origin https://github.com/USERNAME/foto-ke-elemen.git
git push -u origin main
```
Deploy: import repo di Vercel, Framework Preset **Other**, tanpa build command.
